# Gemini Android Chat Client

An enhanced Android chat application built with **Jetpack Compose**, integrating Google's **Gemini Generative AI API** with hardware-backed key security and real-time response streaming.

---

## 1. Where to Place the API Key
Add your Gemini API key inside the root `local.properties` file:

```properties
GEMINI_API_KEY="your_actual_gemini_api_key_here"
