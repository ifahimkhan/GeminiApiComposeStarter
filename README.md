# Gemini API Compose Starter

An Android app built with Kotlin and Jetpack Compose for chatting with Google's Gemini AI model.

## Setup

1. Add your Gemini API key to the local Gradle properties file:

   ```properties
   GEMINI_API_KEY=your_api_key_here
   ```

2. Open the project in Android Studio.
3. Sync Gradle and run the `app` configuration on an emulator or Android device.

> Keep your API key private and do not commit it to version control.

## Features

- Jetpack Compose UI
- Text-based Gemini conversations
- Local conversation persistence
- Material 3 theming
