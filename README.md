## 📱 Features Implemented

1. **API Key Security & Keystore Encryption (Mandatory):**
   - **Local Storage:** API key stored in `local.properties` (`GEMINI_API_KEY=...`), which is git-ignored and never committed to version control.
   - **CI Fallback:** Environment variable fallback in `app/build.gradle.kts` (`System.getenv("GEMINI_API_KEY")`) for automated build environments.
   - **Android Keystore Encryption at Rest:** On first launch, an **AES-256-GCM** key is generated inside the Android Keystore system (`KeyGenParameterSpec`). The key encrypts the API token and stores ciphertext in `EncryptedSharedPreferences`.
   - **Memory-Only Decryption:** The key is decrypted strictly in memory when initializing `GenerativeModel` and is never logged, toasted, or exposed in UI.
   - **R8 Release Obfuscation:** `isMinifyEnabled = true` enables R8 code obfuscation on release builds.

2. **UI Enhancements (Jetpack Compose & Material 3):**
   - **`LazyColumn` Chat List:** Render user and Gemini messages as Material 3 chat bubbles with stable item keys.
   - **Auto-Scroll:** Smooth auto-scrolling to the latest message using `rememberLazyListState()` and `LaunchedEffect`.
   - **State Hoisting:** Stateless composables driven by `ChatUiState` exposed as `StateFlow` from `ChatViewModel`, collected with `collectAsStateWithLifecycle()`.
   - **Responsive Layouts:** Adaptive layouts supporting portrait, landscape, and tablet orientations.
   - **Loading & Error States:** Material 3 progress card overlay ("Gemini is thinking...") during API generation and `SnackbarHost` on error events.
   - **Dark Mode Support:** Material 3 dynamic color scheme with automatic system dark mode detection (`isSystemInDarkTheme()`).

3. **Enhanced Functionality:**
   - **Voice Speech-to-Text Input:** Integrated `RecognizerIntent.ACTION_RECOGNIZE_SPEECH` launched with `rememberLauncherForActivityResult`.
   - **Room Database Persistence:** Chat history saved in a Room database (`AppDatabase`, `ChatDao`, `ChatMessageEntity`) surviving app restarts.
   - **Preferences DataStore:** Manages user settings and model preferences.

4. **Testing:**
   - **Unit Tests:** `ChatViewModelTest` using `kotlinx-coroutines-test` and `FakeGeminiRepository`.
   - **Compose UI Tests:** `ChatScreenTest` using `createComposeRule()`.

## 🔒 Client-Side Security & Production Best Practices

### How Client-Side Encryption Works
In this application, the Gemini API key is encrypted on the device using an AES-256-GCM hardware-backed key generated by the Android Keystore. The key never touches disk in plaintext.

### Security Limits & Architectural Recommendations
While hardware-backed client encryption raises the barrier against static analysis and basic reverse engineering, **client-side encryption alone cannot fully protect a secret from a determined attacker** who has root access or dynamic debugging tools attached to the device.

To fully protect API keys in production:
1. **Backend Proxy / API Gateway:** Route API requests through a secure server backend (e.g., Firebase Cloud Functions or an API gateway). The client authenticates against your backend, and the backend communicates with Gemini using hidden server secrets.
2. **Firebase App Check:** Protect backend resources and API endpoints by verifying that requests originate from your genuine, un-tampered app binary.
3. **Restricted API Keys:** Restrict API keys in Google AI Studio / Google Cloud Console to specific Android package signatures and SHA-1 fingerprints.

## 🚀 Setup & Execution Guide

### 1. Configure local API Key
Create a file named `local.properties` in the root directory (or copy `local.properties.example`):

```properties
GEMINI_API_KEY=your_actual_gemini_api_key_here
```

*(Never commit `local.properties` to Git!)*

### 2. Run the App
Open the project in **Android Studio** and run on an Android Emulator or physical device running API 26 (Android 8.0) or higher.

### 3. Run Unit Tests
To run unit tests for `ChatViewModel`:

```bash
./gradlew test
```

### 4. Run UI Integration Tests
To run Compose UI tests on an emulator/device:

```bash
./gradlew connectedCheck
```
