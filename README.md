# N108 - Gemini Chat Android App

An AI-powered Android chatbot built using Kotlin, Jetpack Compose,
and the Gemini API.

## Features

- Gemini API integration for AI-generated responses
- Voice input
- Concise, Normal, and Detailed response styles
- Persistent chat history using Room Database
- Export chat history using Android's share feature
- Clear chat history with confirmation
- Secure API key storage using Android Keystore
- Responsive Jetpack Compose UI

## Technologies Used

- Kotlin
- Android Studio
- Jetpack Compose
- Google Gemini API
- Room Database
- DataStore
- Android Keystore

## Setup

1. Clone or download this repository.
2. Open the project in Android Studio.
3. Add your Gemini API key using the project's
   local.properties configuration.
4. Sync Gradle.
5. Build and run the application on an Android device
   or emulator.
